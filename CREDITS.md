# 🙏 Credit & Thanks

YouGlideTube Desktop stands on the shoulders of open source. None of this exists without the projects and people below, and this project is grateful to every one of them. This list mirrors the Credit & Thanks of the [YouGlideTube Android app](https://github.com/shivytyahoo/YouGlideTube).

- **Flow Desktop** (https://github.com/Flow-Tube/Flow-Desktop) — special thanks to the original Flow developers for the open-source foundation and the work that helped make YouGlideTube Desktop possible. This app is a fork of Flow Desktop at tag `v0.1.0-beta4` (commit `106a0a2b`, `chore(release): bump version to 0.1.0-beta4 (#657)`), by A-EDev and contributors, licensed GPL-3.0-only. Flow's `LICENSE` file is kept unchanged; this app is also GPL-3.0-only. No relicensing — see `LICENSE`.
- **NewPipe** (https://github.com/TeamNewPipe/NewPipe) — the pioneering open-source YouTube client. The independent-client ecosystem owes NewPipe and its contributors a debt for proving this could be done in the open.
- **Morphe Manager** (https://github.com/MorpheApp/morphe-manager) — design inspiration for this interface. The dark-first surfaces, blue-to-teal brand and glass cards take cues from Morphe Manager's look; its name and logo are not used here.
- **The InnerTube open-source community** — the researchers and developers behind YouTube.js, yt-dlp and the many independent clients whose protocol work makes projects like this possible at all.
- **The libraries that carry the app** — Tauri 2, React 19 and TypeScript, Rust (tokio, reqwest, sqlx), dash.js and hls.js, Zustand, Tailwind CSS, Vite, and the Tauri plugins (deep-link, dialog, notification, opener, os, process, updater).
- **SponsorBlock, DeArrow and Return YouTube Dislike** — community projects that make YouTube better for everyone, kept working here.
- **Shivyt** ([shivytyahoo](https://github.com/shivytyahoo)) — design, development and every late night in between.

If this project makes your day a little better, the credit belongs to all of the above.
