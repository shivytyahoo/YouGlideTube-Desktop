YOUGLIDETUBE DESKTOP CHANGE LOG
VERSION: 1.0.1
DATE: 2026-11-23
STATUS: RELEASE

ABOUT
YouGlideTube Desktop is the desktop version of the YouGlideTube Android app - the same fast, buttery-smooth YouTube client, with the same look, feel and features, rebuilt for the desktop. No ads, no analytics, no telemetry. Sign in with your Google account, or use it without one. This is a fixes-only release on top of 1.0.0.

FIXES IN THIS BUILD
- The "7 months ago" Preview box is gone from Settings > Appearance: it only showed sample dates and was not useful. The Date & Time Display settings themselves are unchanged.
- Liking a comment now moves the count: the like only highlighted before, because the liked-count text was never shown. The same fix covers replies.
- Replying to a comment now shows the reply under it at once: the reply was reaching the server but never appeared until the comments were reloaded. Liking a reply works now too.
- Video like and dislike no longer send a stale token from another video: navigating fast could attach the previous video's token to the like call, and the server refused it. Signed out, tapping like or dislike now opens Google sign-in instead of pretending the like landed locally.
- Volume slider in the narrow player: in the normal watch view the volume button only muted before. Tapping it now opens a small slider above the bar; the wide player keeps the hover slider.
- "Resolving stream" is fixed for good: the playback token was never minted, because the code read the wrong call on YouTube's homepage and failed the whole page. Streams fell back to a legacy token that YouTube refused a few seconds in, so the player stalled on "Resolving stream". Videos that need the fallback now play through.
- Diagnostics now log every like, dislike, comment like and reply call, so the next log shows exactly whether an action reached the server or stopped in the app.
